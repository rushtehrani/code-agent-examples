# Multi-Agent System with OpenAI Agents SDK and DeepEval Evaluation

This project demonstrates a simple multi-agent system built using the `openai-agents-python` SDK and custom evaluations for this system using DeepEval's `DAGMetric`.

## Project Structure

*   `app.py`: Implements the multi-agent system with a `TopicResearcher` and a `SummaryWriter` agent.
*   `evaluate.py`: Implements the DeepEval `DAGMetric` to evaluate the multi-agent system's output.
*   `requirements.txt`: Lists the Python dependencies for this project.
*   `README.md`: This file.

## Multi-Agent System (`app.py`)

The `app.py` script sets up a two-agent system:

1.  **TopicResearcher Agent**:
    *   Takes a research topic as input.
    *   Its role is to find information on this topic. In this demo, it acknowledges the topic and returns a pre-defined block of text (simulating research findings) to ensure deterministic behavior for evaluation.

2.  **SummaryWriter Agent**:
    *   Takes the text output from the `TopicResearcher` as input.
    *   Its role is to generate a concise summary of this text.

The script allows you to provide a research topic via the command line. It then runs the `TopicResearcher` and pipes its output to the `SummaryWriter`, finally printing the generated summary.

## DeepEval Evaluation (`evaluate.py`)

The `evaluate.py` script uses DeepEval to assess the quality of the multi-agent system, focusing primarily on the `SummaryWriter`'s performance within the context of the `DAGMetric`.

The evaluation process is as follows:

1.  **LLMTestCase Setup**:
    *   An `LLMTestCase` is created.
    *   `input`: The research topic.
    *   `expected_output`: The pre-defined research text that the `TopicResearcher` is supposed to produce (and which is fed to the `SummaryWriter`).
    *   `actual_output`: The summary generated by the `SummaryWriter` based on the pre-defined text.

2.  **DAGMetric**:
    *   A `DAGMetric` named "MultiAgentSystemQuality" is defined. This metric uses an LLM-as-a-judge (e.g., GPT-4o) to perform its evaluations.
    *   The DAG consists of two main nodes:
        *   **`InitialOutputCheckNode` (BinaryJudgementNode)**: Checks if the `expected_output` (the researcher's text) is relevant to the `input` topic and is substantial enough. If this check fails, the evaluation results in a low score.
        *   **`SummarizationQualityNode` (NonBinaryJudgementNode)**: If the initial check passes, this node evaluates the quality of the `actual_output` (the summary) compared to the `expected_output` (the original research text). It considers accuracy, completeness, conciseness, and readability. The LLM judge assigns a score based on these criteria.

The script runs this `DAGMetric` on the generated test case and prints the resulting score and reason.

## Setup Instructions

1.  **Clone the repository (if applicable) or ensure all files are in the `jules` directory.**

2.  **Navigate into the project directory:**
    ```bash
    cd jules
    ```

3.  **Create and activate a Python virtual environment (recommended):**
    ```bash
    python -m venv venv
    source venv/bin/activate  # On Windows use `venv\Scripts\activate`
    ```

4.  **Install dependencies:**
    (Ensure you are inside the `jules` directory where `requirements.txt` is located)
    ```bash
    pip install -r requirements.txt
    ```

5.  **Set your OpenAI API Key:**
    (This can be done from any directory, but needs to be set in your terminal session)
    You need an OpenAI API key for both the agents and the DeepEval LLM-as-a-judge to function. Set it as an environment variable:
    ```bash
    export OPENAI_API_KEY='your_openai_api_key_here'
    ```
    On Windows, use:
    ```bash
    set OPENAI_API_KEY=your_openai_api_key_here
    ```
    **Important**: Do not commit your API key to version control.

## How to Run

Ensure your `OPENAI_API_KEY` is set, you have installed the requirements, and you are currently in the `jules` directory.

### Running the Multi-Agent System (`app.py`)

To run the application with a default topic ("Quantum Computing"):
```bash
python app.py
```

To specify a topic:
```bash
python app.py --topic "Artificial Intelligence in Healthcare"
```
The script will print the (pre-defined) researcher output and then the generated summary.

### Running the DeepEval Evaluations (`evaluate.py`)

To run the evaluations with a default topic for the `LLMTestCase` ("Quantum Computing"):
```bash
python evaluate.py
```

To specify a topic for the `LLMTestCase` input:
```bash
python evaluate.py --topic "Climate Change Solutions"
```
The script will print the DeepEval score, reason, and other details from the `DAGMetric`.
